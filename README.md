# Big Noski - Sistem Pencatatan Penjualan dan Belanja Bahan (Vue 3 + Vue Router + Pinia)
Jalankan: `npm install` lalu `npm run dev`.
Akun demo: pemilik / pemilik123 (semua fitur), karyawan / karyawan123 (kasir dan transaksi hari ini).
Data awal ada di `src/seed/*.json`, dimuat ke localStorage saat pertama kali dan tersimpan permanen.
Reset data: hapus key berawalan `bignoski:` di DevTools > Application > Local Storage.
